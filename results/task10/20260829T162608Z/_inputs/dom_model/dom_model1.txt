Context: PyTorch 2.13.0 Release
- Running a torch==2.13.0+rocm7.2 wheel in an environment where no GPU is available ( torch.cuda.is_available() is False ) breaks torch.compile on the CPU path: the first compile raises RuntimeError: Can't detect vectorized ISA for CPU ( #189194 ). This is a regression from torch==2.12.1+rocm7.2 , which compiles CPU code fine (detecting e.g. VecAVX2 ) in the same setup. The 2.13 ROCm wheel appears to rely on something present in the ROCm builder image to detect the CPU vectorized ISA, so it works
