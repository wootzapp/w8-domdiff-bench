- Utility Types
- TypeScript provides several utility types to facilitate common type transformations. These utilities are available globally. Awaited Released: 4.5 This type is meant to model operations like await in async functions, or the .then() method on Promise s - specifically, the way that they recursively unwrap Promise s. Example ts type A = Awaited >; type A = string type B = Awaited >>; type B = number type C = Awaited < boolean | Promise < n
