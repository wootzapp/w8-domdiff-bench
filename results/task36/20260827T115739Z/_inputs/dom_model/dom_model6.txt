- The type operator
- The operator takes an object type and produces a string or numeric literal union of its keys. The following type is the same type as :
- type P = "x" | "y"
- ts type Point = { x : number ; y : number }; type P = keyof Point ; type P = keyof Point Try
- If the type has a or index signature, will return those types instead:
- ts type Arrayish = { [ n : number ]: unknown }; type A = keyof Arrayish ; type A = number type Mapish = { [ k : string ]: boolean }; type M = keyof Mapish ; type M = string | number Try
