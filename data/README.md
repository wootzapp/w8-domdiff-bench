# Benchmark data

The benchmark data is organized into three immutable source collections:

- data-new-dom: original DOM-rich source/reference data.
- data-new-short-dom: refined root-level dom_diffN.txt evidence.
- data-new-screenshot: screenshot evidence for the Microsoft baseline.
- data-short-dom: additional short-DOM task recordings and source artifacts.

Matching task IDs across data-new-short-dom and data-new-screenshot form a
controlled verifier pair. Do not move screenshots into DOM tasks or DOM
observation files into screenshot tasks.
