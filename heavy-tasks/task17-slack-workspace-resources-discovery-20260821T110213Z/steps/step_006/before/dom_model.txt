- Daytona Runner Manager — Operations Guide
- A drop-in replacement for the Helm-managed daytona-runnermanager deployment. Deployed in the tools namespace, uses the same DB, API tokens, and RBAC.
- What It Does
- The runner manager is the bridge between Kubernetes nodes and the Daytona platform . When a new node joins the cluster, this system registers it as a “runner” — a machine that can host developer sandboxes. It then monitors runners, distributes snapshots, and handles scaling.
