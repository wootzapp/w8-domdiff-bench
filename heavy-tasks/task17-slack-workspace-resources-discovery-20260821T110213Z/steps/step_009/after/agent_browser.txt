            - StaticText "The compactor reduces cost by packing sandboxes onto fewer runners and scaling down empty ones."

            - StaticText "  Every 2 minutes:\n         │\n         ▼\n  ┌──────────────────────────────┐\n  │  Count active sandboxes      │\n  │  per runner                  │\n  └──────────┬───────────────────┘\n             │\n             ▼\n  ┌──────────────────────────────┐\n  │  Calculate needed runners:   │\n  │                              │\n  │  capacity = nodeAllocCPU     │\n  │             ÷ avgSandboxCPU  │\n  │                              │\n  │  needed = ⌈ totalSandboxes   │\n  │             ÷ capacity ⌉     │\n  │                              │\n  │  needed = max(needed,        │\n  │               minRunners)    │\n  │                              │\n  │  drain = readyRunners        │\n  │          - needed            │\n  └──────────┬───────────────────┘\n             │ (drain > 0)\n             ▼\n  ┌──────────────────────────────┐\n  │  Select runners to drain:    │\n  │  • Fewest sandboxes first    │\n  │  • Only if all sandboxes     │\n  │    are idle (>30min)         │\n  │  • Verify remaining capacity │\n  │    can absorb the load       │\n  └──────────┬───────────────────┘\n             │\n             ▼\n  ┌──────────────────────────────┐\n  │  Migrate sandboxes:          │\n  │                              │\n  │  stop → wait backup →        │\n  │  restart → verify moved      │\n  │                              │\n  │  (state machine, max 2       │\n  │   concurrent, 3 retries)     │\n  └──────────┬───────────────────┘\n             │\n             ▼\n  ┌──────────────────────────────┐\n  │  Scale down empty runners:   │\n  │  • Decommission in DB        │\n  │  • Cordon + drain node       │\n  │  • Karpenter terminates EC2  │\n  └──────────────────────────────┘\n"
