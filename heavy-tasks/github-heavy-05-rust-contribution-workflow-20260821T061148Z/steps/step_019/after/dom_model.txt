- [10536] Making changes to subtrees and submodules
- For submodules, changes need to be made against the repository corresponding to the submodule, and not the main repository.
- For subtrees, prefer sending a PR against the subtree's repository if it does not need to be made against the main repository (e.g. a rustc-dev-guide change that does not accompany a compiler change).
- [10545] About the rustc-dev-guide
- The rustc-dev-guide is meant to help document how rustc –the Rust compiler– works, as well as to help new contributors get involved in rustc development.
