# Commands

These files record the commands used during the completed runs.

| File | Run |
|---|---|
| `day0_smoke_test.sh` | One-trajectory smoke test |
| `day1_full_uv.sh` | Full 106-trajectory Universal Verifier run |

They are provenance records, not polished one-command rerun scripts. The local
dataset, `.env`, virtual environments, and upstream Fara checkout are ignored
and must exist locally before rerunning.
